## Commands

| Command | Description |
| --- | --- |
| `/wear` | Puts the item in your main hand on your head. |
| `/hat reload` | Reloads `messages.yml`. |

## Permissions

| Permission | Description | Default |
| --- | --- | --- |
| `hat.wear` | Allows using `/wear`. | op |
| `hat.reload` | Allows using `/hat reload`. | op |
